Known limits, stated so the secretariat knows where the system stands:

- **Lao text is OCR.** It is read at 59–89 confidence per page, and rows rest on the 0.65 OCR
  confidence rung. Article numbers OCR misreads are relabelled only where the neighbouring articles
  confirm the sequence, and each relabelling is recorded.
- **Retrieval in these languages needs a translation table.** The rubric's queries are English, and
  of 300 of them, 5 find anything in these corpora. Tables are generated by
  `npm run -w backend translate-queries -- --economy <CODE>` with a declared engine.
- **Dense retrieval needs embeddings.** These require an Ollama host with bge-m3, which the
  development laptop cannot run.
